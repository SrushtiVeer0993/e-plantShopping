# e-plantShopping (Paradise Nursery)

Paradise Nursery is an e-commerce shopping application developed using React and Redux Toolkit. It allows plant enthusiasts to browse various categories of house plants, view details, and manage items in their shopping cart seamlessly.

## Features
- **Landing Page**: Welcome banner with background styling and a "Get Started" button.
- **Product Listing**: Categorized selection of plants with prices, thumbnails, and interactive "Add to Cart" options.
- **Shopping Cart**: Real-time cart calculation, quantity adjustments, item removal, and checkout simulation.
- **State Management**: Built with Redux Toolkit for central state management.
